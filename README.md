## 1. Fundamentos de programación

### 1. Algoritmo

**Definición:** Es una serie de pasos ordenados y finitos que se siguen para resolver un problema o realizar una tarea. Un algoritmo indica qué debe hacerse y en qué orden para obtener un resultado.

**Ejemplo:** Una receta de cocina funciona como un algoritmo: primero se reúnen los ingredientes, después se mezclan y finalmente se cocina el platillo.

**Fuente:** IBM, *What is an algorithm?*

### 2. Programa

**Definición:** Es un conjunto de instrucciones que una computadora puede ejecutar para realizar una actividad específica. Un programa convierte una necesidad o un problema en acciones que la máquina puede llevar a cabo.

**Ejemplo:** Una calculadora digital es un programa porque recibe números y operaciones y después muestra el resultado.

**Fuente:** Encyclopaedia Britannica, *Computer program*.

### 3. Código fuente

**Definición:** Es el texto escrito por una persona mediante un lenguaje de programación. Contiene las instrucciones que después pueden interpretarse o compilarse para que la computadora las ejecute.

**Ejemplo:** La instrucción `print("Hola")` escrita en Python es código fuente.

**Fuente:** MDN Web Docs, *Source code*.

### 4. Lenguaje de programación

**Definición:** Es un sistema de reglas, símbolos y palabras que permite comunicar instrucciones a una computadora. Cada lenguaje tiene características propias y se utiliza para desarrollar distintos tipos de programas.

**Ejemplo:** Python, Java, C++ y JavaScript son lenguajes de programación.

**Fuente:** MDN Web Docs, *Programming language*.

### 5. Sintaxis

**Definición:** Es el conjunto de reglas que indica cómo debe escribirse correctamente el código de un lenguaje. Si se incumplen esas reglas, el programa puede producir un error.

**Ejemplo:** En Python, una instrucción condicional necesita dos puntos después de la condición.

**Fuente:** Python Software Foundation, *The Python Tutorial*.

### 6. Variable

**Definición:** Es un espacio de memoria identificado con un nombre donde se guarda un dato que puede cambiar durante la ejecución de un programa.

**Ejemplo:** Una variable llamada `edad` puede iniciar con el valor 18 y después cambiar a 19.

**Fuente:** Python Software Foundation, *Assignment statements*.

### 7. Constante

**Definición:** Es un valor que se define para mantenerse igual durante el funcionamiento del programa. Se utiliza cuando un dato no debería modificarse accidentalmente.

**Ejemplo:** En un programa de geometría, `PI` puede guardar el valor aproximado de 3.1416.

**Fuente:** Microsoft Learn, *Constants in C#*.

### 8. Tipo de dato

**Definición:** Es la categoría que indica qué clase de información puede almacenar una variable y qué operaciones se pueden realizar con ella.

**Ejemplo:** `25` puede ser un entero, `"Hola"` una cadena de texto y `True` un valor booleano.

**Fuente:** Python Software Foundation, *Built-in Types*.

### 9. Operador

**Definición:** Es un símbolo o palabra que sirve para realizar una operación sobre uno o varios valores, como sumar, comparar o asignar información.

**Ejemplo:** El operador `+` suma dos números y `==` comprueba si dos valores son iguales.

**Fuente:** MDN Web Docs, *Expressions and operators*.

### 10. Expresión

**Definición:** Es una combinación de valores, variables y operadores que, al evaluarse, produce un resultado.

**Ejemplo:** La expresión `precio * cantidad` calcula el costo total de una compra.

**Fuente:** Python Software Foundation, *Expressions*.

### 11. Condicional

**Definición:** Es una estructura que permite tomar decisiones. Ejecuta determinadas instrucciones solamente cuando se cumple una condición.

**Ejemplo:** Un programa puede mostrar “Aprobado” si la calificación es mayor o igual que 70 y “Reprobado” en caso contrario.

**Fuente:** MDN Web Docs, *Making decisions in your code*.

### 12. Bucle

**Definición:** Es una estructura que repite un bloque de instrucciones mientras se cumple una condición o durante una cantidad determinada de veces.

**Ejemplo:** Un bucle puede mostrar los números del 1 al 10 sin escribir diez instrucciones por separado.

**Fuente:** Python Software Foundation, *for Statements and while Statements*.

### 13. Función

**Definición:** Es un bloque de código organizado para realizar una tarea específica. Puede recibir datos, procesarlos y, en algunos casos, devolver un resultado.

**Ejemplo:** Una función llamada `calcular_promedio` puede recibir varias calificaciones y devolver su promedio.

**Fuente:** MDN Web Docs, *Functions*.

### 14. Parámetro

**Definición:** Es una variable que se coloca en la definición de una función para indicar qué información puede recibir cuando sea llamada.

**Ejemplo:** En `saludar(nombre)`, `nombre` es el parámetro que permite personalizar el saludo.

**Fuente:** Python Software Foundation, *Defining Functions*.

### 15. Argumento

**Definición:** Es el valor concreto que se envía a una función cuando se realiza una llamada. Ese valor se asigna al parámetro correspondiente.

**Ejemplo:** En `saludar("Ana")`, el texto “Ana” es el argumento que se entrega al parámetro `nombre`.

**Fuente:** Python Software Foundation, *Defining Functions*.

### 16. Retorno

**Definición:** Es el resultado que una función entrega al lugar desde donde fue llamada. Ese resultado puede utilizarse en otra parte del programa.

**Ejemplo:** Una función que suma dos números puede retornar 8 y guardar ese resultado en una variable.

**Fuente:** Python Software Foundation, *The return statement*.

### 17. Arreglo

**Definición:** Es una estructura que permite almacenar varios datos relacionados dentro de una misma colección, normalmente organizados mediante posiciones o índices.

**Ejemplo:** Un arreglo llamado `calificaciones` puede guardar los valores 85, 90 y 78.

**Fuente:** MDN Web Docs, *Array*.

### 18. Objeto

**Definición:** Es una entidad que reúne datos y comportamientos relacionados. En programación orientada a objetos representa algo con características y acciones.

**Ejemplo:** Un objeto `CuentaBancaria` puede tener `saldo` como dato y `depositar()` como comportamiento.

**Fuente:** MDN Web Docs, *Object-oriented programming*.

### 19. Método

**Definición:** Es una función que pertenece a un objeto o a una clase y que normalmente realiza una acción relacionada con ese objeto.

**Ejemplo:** El método `.append()` de una lista en Python agrega un elemento al final.

**Fuente:** Python Software Foundation, *More on Lists*.

### 20. Evento

**Definición:** Es una acción o cambio que ocurre durante la ejecución de un programa y que puede provocar una respuesta determinada.

**Ejemplo:** Hacer clic en un botón de una página web puede generar un evento que cambie un texto.

**Fuente:** MDN Web Docs, *Introduction to events*.

## 2. Herramientas y desarrollo de software

### 21. Compilador

**Definición:** Es un programa que transforma el código escrito en un lenguaje de programación a código máquina, código intermedio u otra forma que la computadora pueda procesar.

**Ejemplo:** Al compilar un programa en C, se revisa el código y se genera un archivo ejecutable.

**Fuente:** Microsoft Learn; Sommerville (2011).

### 22. Intérprete

**Definición:** Es un programa que procesa y ejecuta instrucciones de un lenguaje durante la ejecución, sin necesitar generar primero un ejecutable completo.

**Ejemplo:** Un intérprete de Python puede ejecutar `print("Hola")` y mostrar el resultado inmediatamente.

**Fuente:** Python Documentation; Sommerville (2011).

### 23. Depurador (Debugger)

**Definición:** Es una herramienta que permite ejecutar un programa de forma controlada para localizar errores. Puede detenerse en puntos específicos y mostrar valores de variables y el flujo de ejecución.

**Ejemplo:** Un programador puede colocar un punto de interrupción para descubrir dónde una variable cambió de 10 a 0.

**Fuente:** Microsoft Visual Studio Documentation; Pressman (2010).

### 24. IDE

**Definición:** Un entorno de desarrollo integrado reúne en una sola aplicación herramientas como editor de código, ejecución, depuración y administración del proyecto.

**Ejemplo:** Visual Studio Code puede configurarse con extensiones para escribir, ejecutar y depurar proyectos.

**Fuente:** Microsoft Visual Studio Code Documentation; Sommerville (2011).

### 25. Editor de código

**Definición:** Es un programa especializado en escribir y modificar archivos de código fuente. Puede ofrecer resaltado de sintaxis y autocompletado, aunque no necesariamente incluye todas las funciones de un IDE.

**Ejemplo:** Usar un editor para abrir un archivo `.js`, modificar una función y guardar los cambios.

**Fuente:** Microsoft Visual Studio Code Documentation.

### 26. Biblioteca (Library)

**Definición:** Es un conjunto de código ya preparado que un programa puede utilizar para realizar tareas específicas sin desarrollarlas desde cero.

**Ejemplo:** Una biblioteca matemática puede proporcionar funciones para calcular raíces, logaritmos o valores trigonométricos.

**Fuente:** MDN Web Docs; Sommerville (2011).

### 27. Framework

**Definición:** Es una estructura de trabajo que proporciona componentes, reglas y una organización base para desarrollar aplicaciones. A menudo establece parte del flujo general del proyecto.

**Ejemplo:** React proporciona herramientas para construir interfaces de usuario mediante componentes.

**Fuente:** MDN Web Docs; Sommerville (2011).

### 28. API

**Definición:** Es una forma definida de comunicación entre programas o componentes. Especifica cómo solicitar funciones o datos sin conocer todos los detalles internos del sistema.

**Ejemplo:** Una aplicación puede usar una API de mapas para solicitar coordenadas y mostrar una ubicación.

**Fuente:** MDN Web Docs; Microsoft Learn.

### 29. Repositorio

**Definición:** Es un espacio donde se almacenan los archivos de un proyecto y, cuando se usa control de versiones, también su historial de cambios.

**Ejemplo:** Un repositorio web puede contener HTML, CSS, JavaScript, documentación y el historial de modificaciones.

**Fuente:** Git Documentation; GitHub Docs.

### 30. Control de versiones

**Definición:** Es un sistema para registrar y administrar los cambios realizados en los archivos de un proyecto. Permite consultar versiones anteriores y facilita la colaboración.

**Ejemplo:** Si una modificación rompe una aplicación, el equipo puede revisar el historial y recuperar una versión anterior.

**Fuente:** Git Documentation; Sommerville (2011).

### 31. Git

**Definición:** Es un sistema distribuido de control de versiones que permite registrar cambios, crear ramas y combinar diferentes líneas de trabajo.

**Ejemplo:** Un programador puede ejecutar `git commit` para guardar un conjunto de cambios en el historial.

**Fuente:** Git Documentation.

### 32. GitHub

**Definición:** Es una plataforma para alojar y colaborar en proyectos que utilizan Git. Permite trabajar con repositorios, ramas, commits y solicitudes de cambio.

**Ejemplo:** Un estudiante puede subir su proyecto a GitHub para conservarlo en línea y compartirlo con su docente.

**Fuente:** GitHub Docs.

### 33. Rama (Branch)

**Definición:** Es una línea independiente de desarrollo dentro de un repositorio. Permite trabajar en una función o corrección sin modificar directamente la línea principal.

**Ejemplo:** Crear una rama llamada `nueva-interfaz` para desarrollar cambios de diseño mientras `main` permanece estable.

**Fuente:** Git Documentation; GitHub Docs.

### 34. Commit

**Definición:** Es un registro que guarda un conjunto de cambios realizados en un repositorio. Normalmente incluye un mensaje que explica lo modificado.

**Ejemplo:** Después de corregir un error, se puede crear un commit con el mensaje “Corregir validación del formulario”.

**Fuente:** Git Documentation; GitHub Docs.

### 35. Merge

**Definición:** Es el proceso de integrar los cambios de una rama con otra. Si existen conflictos, puede ser necesario resolverlos manualmente.

**Ejemplo:** Después de terminar una función en una rama, se hace merge para incorporarla a `main`.

**Fuente:** Git Documentation; GitHub Docs.

### 36. Callback

**Definición:** Es una función que se proporciona a otra función para que sea ejecutada posteriormente cuando ocurre una acción o termina una operación.

**Ejemplo:** En JavaScript, una función puede recibir un callback que se ejecutará cuando termine una solicitud de datos.

**Fuente:** MDN Web Docs.

### 37. Programación síncrona

**Definición:** Es una forma de ejecución en la que las instrucciones se procesan en secuencia: una tarea debe avanzar o terminar antes de que el flujo continúe con la siguiente.

**Ejemplo:** Si un programa realiza tres operaciones de manera síncrona, normalmente espera a terminar la primera antes de comenzar la segunda.

**Fuente:** MDN Web Docs; Sommerville (2011).

### 38. Programación asíncrona

**Definición:** Permite iniciar una operación que puede tardar sin detener todo el flujo del programa mientras se espera el resultado. Cuando la operación termina, se procesa la respuesta.

**Ejemplo:** Una página web puede solicitar información a un servidor y continuar respondiendo a la interfaz mientras espera.

**Fuente:** MDN Web Docs.

### 39. JavaScript

**Definición:** Es un lenguaje de programación utilizado para añadir comportamiento e interactividad a páginas web. También puede ejecutarse fuera del navegador mediante entornos como Node.js.

**Ejemplo:** JavaScript puede detectar que el usuario presionó un botón y cambiar el contenido de una página.

**Fuente:** MDN Web Docs.

### 40. TypeScript

**Definición:** Es un lenguaje basado en JavaScript que agrega tipos estáticos y otras herramientas para facilitar el desarrollo de aplicaciones grandes. El código TypeScript se transforma a JavaScript para ejecutarse en entornos compatibles.

**Ejemplo:** Declarar que una función recibe y devuelve un número permite detectar ciertos errores de tipos antes de ejecutar el programa.

**Fuente:** TypeScript Documentation; Microsoft Learn.

## Conclusión

Los conceptos estudiados abarcan las bases de la programación, las estructuras para construir soluciones y las herramientas que apoyan el desarrollo de software.
